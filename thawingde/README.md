# thawingde

for constraining the thawing scalar-field dark energy model
using DES Year 6 data and external probes. use with modified version of CAMB

**Model:** w(a) = -1 + (1+w₀) exp(−α(1/a − 1))  
---

## Science

The model is the thawing scalar field parameterization from
Shajib & Frieman (2025) [arXiv:2502.06929].

Parameters:

| w₀ | equation of state today | U(−1,−0.33) NEC or U(−2,−0.33) broad |
| α | scalar field shape | U(1.35, 1.55) |

All cosmological priors follow DES Y6 defaults [arXiv:2601.14559]
